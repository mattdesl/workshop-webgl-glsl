This is the interactive guidebook for a workshop on WebGL2 and GLSL ES 3.00.

We'll be using the following tools:

1. [ThreeJS](https://threejs.org) to work with 3D, WebGL, and shaders
2. [canvas-sketch](https://github.com/mattdesl/canvas-sketch/) for exporting prints & animations
3. [Glitch.com](https://glitch.com/) for collecting and demoing some online and easily editable examples

More links:

- [Original Workshop GitHub Repository](https://github.com/mattdesl/workshop-webgl-glsl)

- [Upgraded Workshop GitHub Repository](https://github.com/crimson-aril/workshop-webgl2-glsl-es-3.00/)

FAQs-

1. How to navigate this book?

    - Use the left & right arrows in the nav bar
    or
    - press the left & right arrows of the keyboard
    or
    - press the a & d key of the keyboard
    or
    - use the Previous and Next buttons at the end of each slide

2. How to open & close the sidebar

    - Press shift key on keyboard
    or
    - use the icon on top left

3. How to open the canvas in full screen

    - Press or tap the full screen button
    or
    - use the spacebar of keyboard

4. How to exit the canvas in full screen

    - Use Esc or spacebar again

5. What if i wrote wrong code in the editor?
    - Use the refresh button
    or
    - press alt + x on keyboard

6. How to copy code(s)?
    - Use the copy button
    or
    - press alt + c on keyboard
